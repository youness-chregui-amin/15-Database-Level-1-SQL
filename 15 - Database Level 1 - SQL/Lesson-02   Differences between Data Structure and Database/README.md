# Lesson 02 - Differences between Data Structure and Database

---

# Introduction

In this lesson, we learned the main differences between:

* **Data Structures**
* **Databases**

Both are used to work with data, but each one has a completely different purpose and environment.

---

# What is Data Structure?

A **Data Structure** is a special way to organize and store data inside the program memory (RAM).

It helps programmers:

<ul>
  <li>Process data efficiently</li>
  <li>Improve performance</li>
  <li>Reduce program complexity</li>
</ul>

### Important Notes

<ul>
  <li>Stored in <strong>RAM</strong></li>
  <li>Temporary data (<strong>Volatile Memory</strong>)</li>
  <li>Used during program execution</li>
  <li>Controlled by programming languages</li>
</ul>

### Languages Used

<ul>
  <li>C++</li>
  <li>Java</li>
  <li>Python</li>
  <li>C#</li>
</ul>

### Examples of Data Structures

<ul>
  <li>Array</li>
  <li>Linked List</li>
  <li>Stack</li>
  <li>Queue</li>
  <li>Tree</li>
  <li>Graph</li>
</ul>

---

# What is Database?

A **Database** is an organized collection of data stored permanently on disk storage.

It is used to:

<ul>
  <li>Store huge amounts of data</li>
  <li>Manage data easily</li>
  <li>Retrieve data quickly</li>
  <li>Keep data permanently</li>
</ul>

### Important Notes

<ul>
  <li>Stored on <strong>Hard Disk / SSD</strong></li>
  <li>Permanent data (<strong>Non-Volatile Memory</strong>)</li>
  <li>Exists outside the program</li>
  <li>Managed using DBMS systems</li>
</ul>

### Database Systems Examples

<ul>
  <li>MySQL</li>
  <li>SQL Server</li>
  <li>Oracle</li>
  <li>PostgreSQL</li>
  <li>MongoDB</li>
</ul>

### Language Used

<ul>
  <li>SQL (Structured Query Language)</li>
</ul>

---

# Differences Between Data Structure and Database

| Data Structure                        | Database                             |
| ------------------------------------- | ------------------------------------ |
| Stored in RAM                         | Stored on Hard Disk                  |
| Temporary (Volatile)                  | Permanent (Non-Volatile)             |
| Used inside programs                  | Used outside programs                |
| Focuses on performance and algorithms | Focuses on storing and managing data |
| Controlled by programming languages   | Controlled by DBMS                   |
| Handles small/runtime data            | Handles large/persistent data        |
| Examples: Stack, Queue, Tree          | Examples: MySQL, Oracle              |

---

# Key Takeaway

<ul>
  <li><strong>Data Structures</strong> help programs process data efficiently during execution.</li>
  <li><strong>Databases</strong> help applications store and manage data permanently.</li>
</ul>

Both are essential in software development and work together in real-world applications.

---

# Simple Real-World Example

### Data Structure

When a game stores player actions temporarily while the game is running → it uses Data Structures.

### Database

When the game saves player accounts and scores permanently → it uses a Database.

---

# Summary

<ul>
  <li>Data Structures → Temporary + Fast Processing</li>
  <li>Databases → Permanent + Data Management</li>
  <li>Data Structures work in memory (RAM)</li>
  <li>Databases work in storage devices</li>
  <li>SQL is used with databases</li>
  <li>Programming languages use Data Structures internally</li>
</ul>

# الفرق بين Data Structure و Database

</div>

| Data Structure                                 | Database                                 |
| ---------------------------------------------- | ---------------------------------------- |
| كتتخزن فـ RAM                                  | كتتخزن فـ Hard Disk                      |
| مؤقتة (Volatile)                               | دائمة (Non-Volatile)                     |
| كتستعمل داخل البرامج                           | كتستعمل خارج البرامج                     |
| التركيز ديالها على الأداء والخوارزميات         | التركيز ديالها على تخزين وتسيير البيانات |
| كيتحكم فيها لغات البرمجة                       | كيتحكم فيها DBMS                         |
| كتتعامل مع بيانات صغيرة أو مؤقتة أثناء التشغيل | كتتعامل مع بيانات كبيرة ودائمة           |
| أمثلة: Stack, Queue, Tree                      | أمثلة: MySQL, Oracle                     |

# الخلاصة المهمة

</div>

<ul dir="rtl">
  <li><strong>Data Structures</strong> كيساعدو البرامج تعالج البيانات بكفاءة أثناء التشغيل.</li>
  <li><strong>Databases</strong> كيساعدو التطبيقات تخزن وتسير البيانات بشكل دائم.</li>
</ul>

<div dir="rtl" align="right">
