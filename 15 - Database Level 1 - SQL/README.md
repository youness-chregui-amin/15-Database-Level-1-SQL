# Database Level 1 — SQL

A structured learning repository focused on SQL, relational databases, database design, and practical querying.

---

## About

This repository documents my progress through **Database Level 1 — SQL** by **Dr. Mohammed Abu-Hadhoud**.

The course is part of my programming foundations roadmap and focuses on understanding how relational databases work, how they are designed, and how SQL is used to work with real-world data.

## What I Am Learning

The course covers both database concepts and practical SQL development.

### Database Concepts

* Databases and DBMS
* RDBMS
* Data, Information, Knowledge, and Wisdom
* NULL values
* Data redundancy
* Data integrity
* Primary Keys and Foreign Keys
* Database constraints

### Database Design

* Entity Relationship Diagrams (ERD)
* Entities and Weak Entities
* Attributes
* Relationships
* Cardinality and Ordinality
* Participation
* Associative Entities
* Generalization and Specialization
* Relational Schema
* Converting ERD designs into relational schemas

### SQL

* Creating and removing databases
* Creating and modifying tables
* SQL data types
* ALTER TABLE
* INSERT
* UPDATE
* DELETE
* SELECT
* DISTINCT
* WHERE
* AND / OR / NOT
* IN
* BETWEEN
* ORDER BY
* TOP
* Aliases
* LIKE and Wildcards
* Aggregate Functions
* GROUP BY
* HAVING
* CASE
* UNION
* UNION ALL
* EXISTS
* NOT EXISTS
* Views
* JOINs

### Constraints and Data Integrity

* PRIMARY KEY
* FOREIGN KEY
* UNIQUE
* NOT NULL
* CHECK
* DEFAULT
* INDEX

### Database Normalization

* Normalization fundamentals
* First Normal Form (1NF)
* Second Normal Form (2NF)
* Third Normal Form (3NF)

## Learning Method

My approach throughout this course is based on practice rather than only watching lessons.

```text
Learn
  ↓
Take Notes
  ↓
Write SQL
  ↓
Practice
  ↓
Solve Problems
  ↓
Document
```

The purpose is to understand why each SQL statement works and how the concepts can be applied when building real applications.

---

## Practical Focus

One of the main goals of this repository is to move from simply knowing SQL syntax to understanding how databases are structured.

This includes:

* Designing tables correctly
* Defining relationships
* Maintaining data integrity
* Writing readable SQL queries
* Working with related tables
* Understanding database normalization
* Thinking about data before writing application code
