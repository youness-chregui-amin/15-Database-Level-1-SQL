# Lesson 01 — Differences Between Data, Information, Knowledge, and Wisdom

## Author

Youness Chergui Amin

---

## Overview

Understanding the difference between:

* Data

* Information

* Knowledge

* Wisdom

---

## DIKW Model

Data → Information → Knowledge → Wisdom

---

## Data

Raw facts without meaning.

Example: 100, Youness, 85

---

## Information

Processed data with meaning.

Example: Youness scored 85 marks.

---

## Knowledge

Understanding patterns.

Example: Youness is good at programming.

---

## Wisdom

Making smart decisions.

Example: Youness should become a developer.

---

## Comparison

| Concept     | Meaning       |
| ----------- | ------------- |
| Data        | Raw           |
| Information | Meaning       |
| Knowledge   | Understanding |
| Wisdom      | Decision      |

---

## Key Takeaways

* Data = Input

* Information = Meaning

* Knowledge = Understanding

* Wisdom = Decision

## نموذج DIKW

البيانات → المعلومات → المعرفة → الحكمة

---

## البيانات (Data)

هي معطيات خام مازال ما عندهاش معنى واضح بوحدها۔

**مثال:** 100، Youness، 85۔

---

## المعلومات (Information)

هي البيانات من بعد ما كتتعالج وكتولي عندها معنى۔

**مثال:** Youness جاب 85 نقطة۔

---

## المعرفة (Knowledge)

هي الفهم ديال المعلومات والقدرة على اكتشاف الأنماط والعلاقات بينها۔

**مثال:** Youness مزيان فالبرمجة۔

---

## الحكمة (Wisdom)

هي استعمال المعرفة باش ناخدو قرارات ذكية ومناسبة۔

**مثال:** Youness خاصو يولي Developer۔

---

## المقارنة

| ----------- | ---------- |
| Data        | معطيات خام |
| Information | معنى       |
| Knowledge   | فهم        |
| Wisdom      | قرار       |
